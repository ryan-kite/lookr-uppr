# lookr-uppr Project Setup Blueprint

## Board Type
GitHub Project (table + board views)

## Columns
- Backlog
- Ready
- In Progress
- In Review
- Blocked
- Done

## Labels
### Priority
- `P0` Critical
- `P1` High
- `P2` Medium
- `P3` Nice-to-have

### Domain
- `domain:design-system`
- `domain:frontend`
- `domain:data-ingestion`
- `domain:scoring`
- `domain:ios-integration`
- `domain:qa-release`

### Type
- `type:epic`
- `type:feature`
- `type:task`
- `type:bug`

## Epics
1. Product & Design System
2. Modernization (Vue 3 + TypeScript + PWA shell)
3. Open-source Data/Scoring Engine
4. iOS Integration (shortcut/action button + call identification path)
5. QA, Family Pilot, Launch

## Governance Cadence
- Weekly planning + reprioritization
- Mid-week risk review (blocked items, dependency issues)
- Weekly demo and family-user feedback summary

## Definition of Ready
- Problem statement and user value are clear
- Acceptance criteria are testable
- Dependencies called out
- Priority and domain labels assigned

## Definition of Done
- Acceptance criteria met
- UX/accessibility checks completed
- Relevant docs updated
- QA notes attached
